# 🎓 Student Performance Prediction System

A machine learning-based web application that predicts student academic performance using historical academic and socio-economic data. The application is built with Flask and Scikit-learn and provides real-time performance predictions through a simple web interface.

## Features

* Predicts student academic performance using a trained regression model.
* Trained on a dataset containing over **2,500 student records**.
* Uses **15+ academic and socio-economic features** for prediction.
* Achieves approximately **87% prediction accuracy**.
* Generates real-time predictions in under **2 seconds**.
* Produces automated performance reports with visualizations.

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Bhawana-Bisht/student-performance-prediction.git
```

2. Navigate to the project directory:

```bash
cd student-performance-prediction
```

3. Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Running the Project

Train the model:

```bash
python train_model.py
```

Start the Flask application:

```bash
python app/app.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000/
```
