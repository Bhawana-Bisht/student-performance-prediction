## Student Performance Prediction System

- Built a machine learning web application using Flask and Scikit-learn
- Trained regression model on 2,500+ student records
- Engineered 15+ academic and socio-economic features
- Achieved ~87% prediction accuracy
- Real-time predictions under 2 seconds
- Automated performance reports with visualizations

### Tech Stack
Python, Pandas, NumPy, Scikit-learn, Flask, Matplotlib

```bash
python train_model.py
